## Reporting a Security Vulnerability

We take security seriously, especially regarding data exfiltration, token leaks, and prompt injection attacks. 

If you discover a security vulnerability or guardrail bypass in **AI-Lab-Hybrid-DASSensei**:

1. **Do NOT open a public GitHub issue.**
2. Please report your findings privately via email to: **security@dassensei.org** (or use GitHub Private Vulnerability Reporting under the "Security" tab).
3. Include:
   - Description of the vulnerability or guardrail bypass.
   - Steps to reproduce (including prompt samples or data payloads).
   - Potential impact on local/cloud execution environments.

We will acknowledge receipt within 48 hours and work with you to patch the issue before public disclosure.
